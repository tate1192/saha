# Field Operation Disinfect Common

`field_operation_disinfect` ve `field_operation_forms_disinfect` modüllerinin
ortak katalog ve metadata sahibidir. Dezenfeksiyon ürünleri, `disinfect` servis
tipi ve şirket sertifika alanı iki bağımsız akış tarafından paylaşılır.

Bu modül forms'a bağımlı değildir. Operation veya forms modüllerinden biri
kaldırıldığında ortak kayıtlar diğer modül için korunur.
