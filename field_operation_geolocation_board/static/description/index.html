Günün Rotaları — Dispatcher Route Board

Odoo 19 · Softteknik Bilişim · AGPL-3

One screen with the whole day's routes: every team's route on a single map in its own colour, numbered stops, the start/end point of the loop, live positions and a filter panel on the right. Built on top of Field Operation Geolocation and Soft Web Map (Leaflet), installed automatically when both are present.

What it does

  • Menu Field Operation > Daily Routes and a Routes button on the team form.
  • Coloured closed-loop polylines, numbered stop pins, home/depot start marker, live team markers.
  • Right panel: per-team stops/missing coordinates/km/last seen, search, filters (Online only, Route not saved, Missing coordinates), solo mode, fit-to-team.
  • Stop popup with customer, time, district, address, phone and Open Job / Directions actions.
  • Date navigation (previous / today / tomorrow / picker), live polling every 45 s, day KPIs and totals.

Access

The board is a dispatcher screen: menu and JSON endpoints require the Head Office group of Field Operation. Field workers cannot open it or read the other teams' routes.

Limitations of this version

  • Read-only: reorder and save through the existing daily plan wizard (pencil on a team).
  • Route geometry is a straight line (haversine); real road geometry / ETA comes later.
  • Unassigned jobs are only counted, not drawn.
  • Browser/OWL/Leaflet behaviour must be checked in staging; the module install and the Python test suite are green.
